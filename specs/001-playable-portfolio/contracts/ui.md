# UI contracts
- Start exploration switches overview to drive; exit returns overview without browser history changes.
- WASD/arrows or four touch buttons move along streets; reset restores the starting road position.
- Space/E opens nearest landmark when close; selecting scene markers or project list entries opens the same named dialog.
- Escape closes dialogs and restores focus, or exits exploration when no dialog is open.
- Projects button opens a keyboard-accessible directory; all project links remain available when graphics fail.
- Activity summary provides dated source and an expandable list of positive days; selected tower shows date and contribution count.
- Motion toggle controls automatic overview orbit and reports aria-pressed state. Reduced motion defaults it off.
- No activity is inferred from decorative skyline or project buildings.
