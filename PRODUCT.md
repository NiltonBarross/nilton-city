# Product
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Delegated through the user's “Pode criar” after the proposed static HTML/CSS/JavaScript approach. Static deployment prepared for GitHub Pages; Sites provides the hosted preview.

## Users
Visitors to NiltonBarross's GitHub evaluating projects, and the owner exploring his activity as a small game.

## Product Purpose
A personalized GitHub profile and portfolio. Visitors explore a playable city derived from public contributions and discover actual projects.

## Positioning
The city is an alternate navigation for the public portfolio, backed by a dated GitHub activity snapshot.

## Operating Context
Desktop keyboard/mouse and mobile touch. Visitors can also browse the project list directly.

## Capabilities and Constraints
Explorable city; contribution-based buildings; selectable projects; accessible non-game list; public repository links; profile README linked to the portfolio. No backend, sign-in or private repository exposure.

## Brand Commitments
User explicitly selected GTA VI / GitGTA inspiration, purple and pink city reference screenshot, and the playable buildings experience. Display name Nilton Luan and focus in data, automation and AI were proposed and approved by “Pode criar.” Original artwork, not a copy of game branding.

## Evidence on Hand
Public repository READMEs: Market Atlas, Mapa do Brasil, QR Code offline, Job Hunter AI, Twitter article PDF exporter, YouTube transcription script. GitHub API confirms calendar and seven public repositories at initial capture. The private scripts repository is excluded. No career history or contact information has been confirmed.

## Product Principles
- Explore before reading, but never require gameplay to reach projects.
- Distinguish public contributions from commits and scenery from data.
- Keep project descriptions grounded in repository evidence.
- Work from a bundled snapshot when no live service is available.
