# Nilton Luan

**Dados, automação & IA.**

Construo ferramentas para explorar dados, estudar mercados e automatizar tarefas. Este perfil reúne projetos que você pode abrir, usar e inspecionar.

### Entre na minha cidade

Meu portfólio é uma cidade 3D: dê uma volta de carro, visite os prédios dos projetos e descubra as torres dos dias com contribuições no GitHub.
